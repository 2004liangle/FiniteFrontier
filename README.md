# 失落机甲 · Finite Frontier

《王国：两位君主》玩家制作 Mod。驾驶机甲，探索每日海岛新增区域。  
A fan-made mod for Kingdom Two Crowns. Pilot a mech and explore new regions in the Daily Challenge.

![失落机甲宣传海报 / Finite Frontier poster](poster.png)

[下载 v0.5 免费公测 / Download v0.5 Public Beta](https://github.com/2004liangle/FiniteFrontier/releases/tag/v0.5.0-pt.1)

**兼容 / Compatibility** · Windows 64 位 / 64-bit · Kingdom Two Crowns 2.3.1 rev23072

**安装 / Install**  
关闭游戏，将 ZIP 解压到 KingdomTwoCrowns.exe 所在目录，再启动游戏。  
Close the game, extract the ZIP into the folder containing KingdomTwoCrowns.exe, and relaunch.
