# 失落机甲 · Finite Frontier

《王国：两位君主》的玩家制作 Mod。v0.5 免费公测适配 Windows 64 位、游戏 **2.3.1 rev23072**。

[下载 v0.5 公测包](https://github.com/2004liangle/FiniteFrontier/releases/tag/v0.5.0-pt.1)

驾驶机甲起飞并释放巡飞弹。随主城成长升级技能，探索每日海岛新增区域，并体验商店预付、税务官拾币和友军传送门。

## 安装

关闭游戏，解压发布附件，将解压后的文件复制到与 KingdomTwoCrowns.exe 同级的游戏目录，再启动游戏。
